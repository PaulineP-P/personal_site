# вне сети — личный дневник-трекер

Одна страница (`index.html`), без сервера. Данные хранятся в браузере (localStorage) на одном устройстве.

## Как запустить на GitHub Pages
1. Создай новый репозиторий на github.com (например, `vne-seti`). Можно приватный только при платном плане; для бесплатного Pages — публичный (данные всё равно не попадают в репозиторий, они живут в твоём браузере).
2. Нажми **Add file → Upload files**, загрузи `index.html` (и этот README), нажми **Commit changes**.
3. Открой **Settings → Pages**: Source — *Deploy from a branch*, Branch — `main`, папка `/ (root)`, **Save**.
4. Через 1–2 минуты сайт будет по адресу `https://<твой-логин>.github.io/vne-seti/`.
5. На телефоне: открой адрес в Safari → «Поделиться» → «На экран Домой».

## Важно про данные
- Всё хранится только в браузере, где ты отмечаешь. Другое устройство или другой браузер = пустой дневник.
- Раз в неделю: **Настройки → Скачать копию (.json)**. Восстановить — «Загрузить копию».
- Очистка данных сайта / истории браузера удалит дневник, если нет копии.
